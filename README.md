# 国会の日数（kokkai-nissu）

衆議院の解散と総選挙・国会の召集・常会の会期・参議院の緊急集会・憲法改正の国民投票・法律案や予算や条約の議決・総理大臣の指名・不信任・法律の公布・裁判官の任期と国民審査・検査官や人事官などの任期の場面を読んで、その日数か年数（10日・30日・40日・60日・150日・180日・4年・5年・10年・12年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（解散・選挙・召集／国会の議決／任期と審査）も選ぶ。国会のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/kokkai-nissu/>

- 中身は e-Gov 法令検索の日本国憲法（<https://laws.e-gov.go.jp/law/321CONSTITUTION>）第54・59・60・61・67・69・79・80条、国会法（<https://laws.e-gov.go.jp/law/322AC1000000079>）第2条の3・第10・66条、日本国憲法の改正手続に関する法律（<https://laws.e-gov.go.jp/law/419AC1000000051>）第2条、会計検査院法（<https://laws.e-gov.go.jp/law/322AC0000000073>）第5条、国家公務員法（<https://laws.e-gov.go.jp/law/322AC0000000120>）第7条、独占禁止法（<https://laws.e-gov.go.jp/law/322AC0000000054>）第30条、日本銀行法（<https://laws.e-gov.go.jp/law/409AC0000000089>）第24条に書いてある日数と任期だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。議員の任期・選挙の投票・人数や賛成の割合は省いています。公式の情報の代わりではありません。実際のことは、衆議院・参議院の案内や専門家に確かめてください。
- 選挙のしくみ（senkyo-shikumi）の議員の任期・投票と、憲法のしくみ（kenpo-shikumi）のだれがする仕事かとは重ねていません。
- 2段目は、きまりの種類で分けています。
